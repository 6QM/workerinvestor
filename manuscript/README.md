这里保存最终书稿章节草稿。

当前本地结构已同步到 Notion 的《The Worker Investor / 工资之外》章节数据库。Notion 是当前 source of truth；本地仓库负责版本化、发布和备份。

## 命名规则

`NN-chapter-title.md`

示例：

- `01-why-i-started-thinking-worker-investor.md`
- `08-etf-financial-core.md`
- `13-meta-review-and-rebalancing.md`
- `99-conclusion-becoming-worker-investor.md`

## 书稿规则

- 章节不是逐字稿整理，也不是视频稿的直接拼接。
- 每章都要有清晰的推进作用。
- 每章至少支撑一个核心母句或核心模型。
- 章节之间要有过渡，避免读起来像文章合集。
- `Status = Not started` 不等于内容为空；有些 Notion 页面已经有大量研究底稿，需要单独整理。
