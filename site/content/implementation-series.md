# The Worker Investor Implementation Series

This roadmap keeps future AI/code/design work scoped. Do one series at a time.

## Series 1: Reference Research

Goal: establish taste and judgment.

Deliverables:

- `01_reference-board.fig`
- `02_visual-analysis.md`
- `03_design-principles.md`

Output should explain what to borrow from Stripe Press, Designing Your Life, Building a Second Brain, Navalmanack, and strong nonfiction author sites.

## Series 2: Book Identity System

Goal: make The Worker Investor visually recognizable.

Deliverables:

- wordmark direction;
- color tokens;
- typography system;
- cover directions;
- icon/symbol system;
- diagram style;
- social preview style.

## Series 3: Book Object Design

Goal: make the book feel real before it is finished.

Deliverables:

- front cover concept;
- back cover concept;
- spine concept;
- 3D book mockup;
- flat cover image;
- social cover image.

Start with three cover directions:

- Minimal Typography;
- Salary-to-Asset Diagram;
- Worker Object Symbol.

## Series 4: Landing Page v0.1

Goal: make the first page explain the book, the problem, the method, and the next action.

Modules:

- Hero;
- Problem;
- Promise;
- Core Ideas;
- Table of Contents;
- Sample Chapter;
- Resources;
- Author Note;
- Newsletter CTA.

## Series 5: Living Book

Goal: allow chapters to be published gradually.

Routes:

- `/read/`
- `/read/preface/`
- `/read/chapter-01/`

Chapter structure:

- title;
- opening question;
- core thesis;
- essay;
- diagrams;
- case notes;
- key takeaways;
- related concepts;
- related tools;
- version history.

## Series 6: Resource & Toolkit

Goal: turn reading into practice.

First tools:

- Payday Allocation Sheet;
- Human Capital ETF Self-Assessment;
- Core / Growth / Distribution / Meta allocation sheet;
- 90-Day Worker Investor Plan;
- Weekly Review Sheet;
- Annual Human Capital Report.

## Series 7: Trust Layer

Goal: reduce reader doubt and show long-term seriousness.

Add:

- author page;
- writing progress;
- version record;
- references;
- sample chapter;
- case library;
- newsletter archive;
- reader feedback later.

## Series 8: Launch System

Goal: make publishing repeatable.

Cadence:

- weekly: Worker Investor Notes;
- every two weeks: one case study;
- monthly: one template/tool;
- quarterly: version update;
- twice a year: public report.

Infrastructure:

- RSS;
- sitemap;
- newsletter signup;
- SEO metadata;
- OG images;
- search;
- version history;
- analytics;
- GitHub-based publishing.

## MVP Scope

The first public version only needs:

1. cover concept v0.1;
2. 3D book mockup;
3. landing page;
4. manifesto;
5. table of contents;
6. newsletter entry.

Second version:

1. sample chapter;
2. resources page;
3. HCE self-assessment;
4. case library.
