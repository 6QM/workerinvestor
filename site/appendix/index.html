更新协议Update protocol

每次新增内容，都先判断它该放在哪里。Every new item must first answer where it belongs.

  1. 能代表长期主张：进书。If it represents the long-term thesis: enter the book.
  2. 太细、太技术、但有价值：进活附录。If it is detailed, technical, but useful: enter the living appendix.
  3. 和当下世界变化有关：发成 post。If it responds to the changing world: publish it as a post.
  4. 还没想清楚：留在私人草稿。If it is not clear yet: keep it private.
