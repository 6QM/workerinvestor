Practice loopPractice loop

工具不追求复杂，先让配置被看见。The tools should not be complex. They should first make allocation visible.

  1. 记录工资现金流。Record wage cash flow.
  2. 分配 Core / Growth / Distribution / Meta。Allocate Core / Growth / Distribution / Meta.
  3. 每周复盘一次最小行动。Review one minimum action each week.
  4. 每季度再平衡一次方向。Rebalance direction each quarter.
