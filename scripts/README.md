# Scripts

这里保存从书稿衍生出来的视频稿、文章稿和发布脚本。

本项目的主任务是写书。`scripts/` 不是书稿前置区，而是分发区：当 `manuscript/` 中的章节已经形成后，可以从章节中提炼视频、文章或网站内容。

## 命名规则

`NNN-topic.md`

示例：

- `001-why-the-worker-investor.md`
- `002-the-worker-investor-100-episode-bank.md`
- `002-salary-is-cashflow.md`
- `010-ai-worker-boundary.md`

## 分发稿结构

```markdown
# 标题

## 开场

用一个真实问题或场景进入。

## 核心观点

一句话说明这篇分发内容想讲什么。

## 结构

1. 
2. 
3. 

## 正文

分段展开。

## 收束

回到 The Worker Investor 的主线。
```

## 书稿转分发稿规则

- 先确认对应章节已经存在或正在成形。
- 不新增与书稿主线冲突的观点。
- 保留章节核心母句和模型。
- 可以增强开场和口语节奏，但不能反过来让书稿服从视频节奏。
