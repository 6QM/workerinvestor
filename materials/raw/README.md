# Raw Materials

这里保存用户后续直接粘贴的 ChatGPT 对话原始素材。

## 命名规则

建议格式：

`YYYY-MM-DD-topic.md`

示例：

- `2026-05-15-worker-investor-positioning.md`
- `2026-05-20-fire-and-choice.md`
- `2026-06-01-human-capital-etf.md`

## 文件模板

```markdown
# 原始素材：主题

日期：
来源：用户粘贴的 ChatGPT 对话
隐私级别：默认本地归档，不公开原文
可能归属章节：

## 原文

在这里粘贴原始素材。
```

## 隐私默认

raw 原文只用于写作追溯，不默认公开进入书稿。涉及公司、项目、人物、薪资、资产数字和账号的信息，进入书稿前必须匿名化或抽象化。
