## 提炼原则

- 不直接复制长段原始对话。
- 优先提炼结构、问题、判断和母句。
- 每条 processed note 至少标注一个可能归属章节。
- 如果素材可以支持多个章节，按主章节和副章节记录。
- 默认优先进入书稿；视频、文章和网站内容只是后续分发形态。
